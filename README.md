# GossiGo web sayfası

GossiGo’nun Türkçe landing page’i `index.html` dosyasında bulunur. Sayfa, koyu temalı özgün tasarımı kullanır.

| Sayfa | Dosya | Yayınlandıktan sonraki adres |
| --- | --- | --- |
| Ana sayfa | `index.html` | `/` veya `/index.html` |

Repo, GitHub Pages üzerinden `master` branch’inin kök dizininden yayınlanır. Özel alan adı `CNAME` dosyasında tanımlıdır.

## Yerel önizleme

`index.html` dosyasını tarayıcıda doğrudan açabilir veya repo dizininde basit bir sunucu başlatabilirsiniz:

```sh
python3 -m http.server 8000
```

Önizleme adresi: http://localhost:8000/

Derleme veya paket kurulumu gerekmez. Sayfa JavaScript kullanmaz. Yazı tipleri Google Fonts’tan yüklenir; bağlantı olmadığında sistemin sans-serif yazı tipi kullanılır.

Uygulama örnekleri temsilidir. Erken erişim bağlantısı `info@startyazilim.com` adresine e-posta oluşturur; form verisi toplanmaz. Uygulama yayınlandığında mağaza bağlantıları ve “yakında” metinleri güncellenmelidir.
